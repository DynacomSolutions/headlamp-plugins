# README screenshots

These PNGs show the running Headlamp plugins. Identifying text was replaced
in the rendered browser DOM before capture, including cluster and worker
names, projects, application URLs, namespaces, services, runner pools,
notification channels and device labels. The changes were local to the
browser; no cluster resources or backend data were changed.

The screenshots illustrate the UI rather than providing sample monitoring
data to import. To refresh them, capture the relevant page after replacing
all identifying text with generic examples, then review the complete image
before adding it to this public repository. Check warning lists, table rows,
filters, aliases and job details as well as page headings.
